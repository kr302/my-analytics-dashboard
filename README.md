# 📊 Expense Tracker Pro & Visual Analytics Dashboard

A responsive budget management microproject with real-time analytics charts and data export functionalities.

## ✨ Key Features
- **Data Persistence**: Uses Browser LocalStorage for seamless data retention.
- **Live Analytics**: Dynamic bar graphs using Chart.js.
- **CSV Data Export**: One-click download for transaction history.
- **Responsive Design**: Built using Bootstrap 5.

## 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Libraries: Chart.js, Bootstrap 5
- Deployment: GitHub Pages
